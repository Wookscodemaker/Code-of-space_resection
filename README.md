# Code-of-space_resection
### 单像空间后方交会的程序实现。这个项目为课程作业，上传至github方便程序的编写以及后续的分享。
#### Thouse days my specialized course photogrammetry has a homework to code a program to implemente the space resection.This repository's aim is to finish the programe.And share the programe to someone will learn this course in the future.
>### 本项目在矩阵的计算上使用了eigen库，在项目中包括了eigen这个头文件库，在下方示出eigen的官网，方便大家查看。
>#### This project uses the Eigen library for matrix calculations and includes its header files. The official Eigen website is provided below for your reference.
> https://libeigen.gitlab.io/
